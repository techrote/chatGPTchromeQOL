# ChatGPT Model / Effort Ledger — prototype

Records each **confirmed** user send with:

- ISO timestamp
- page/chat URL
- prompt character count
- visible composer control text
- conservative model classification
- visible reasoning-effort classification

Click the fixed **Ledger** badge to inspect recent entries and optionally download the full local JSON ledger.

This is deliberately a UI-observation ledger, not authoritative OpenAI billing/quota data.
