# ChatGPT Chat Project Index — prototype

Builds a local map from ChatGPT conversation URL to detected project context.

Indexed signals:

- GitHub repositories mentioned in the thread
- task/programme IDs matching forms such as `SDVK-010`, `FNR-003`, `PP-004`

The fixed badge reports the current thread's detected context. Click it to inspect recent indexed chats or export the complete JSON index.

No transcript text is stored by this prototype—only chat URL/title and extracted repo/task identifiers.
